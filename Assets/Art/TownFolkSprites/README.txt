Town Folk Sprites
24 pixel art icons, 16x16, transparent PNG.

Folders 16x16 / 32x32 / 64x64: one PNG per icon (nearest-neighbour upscales, no blur).
spritesheet_*.png: all icons, 8 per row. spritesheet.json: frame positions.
Tip: set your engine's texture filter to 'nearest' / 'point' so pixels stay sharp.
