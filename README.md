# Xenomorph

Unity game for CSCI 3836 (Saint Mary's University), group project.

## Setup
1. Install [Git LFS](https://git-lfs.com) once: `git lfs install`
2. Clone: `git clone https://github.com/Guard33/xenomite.git`
3. Open the folder in Unity Hub (everyone use the same Unity version).

**Read [CONTRIBUTING.md](CONTRIBUTING.md) for the full branch → commit → pull request workflow.**

## Rules to avoid merge pain
- `git pull` before you start working, commit and push often.
- Don't edit the same scene at the same time. Work in your own scene or prefab, and say in the group chat before touching a shared scene.
- Use branches for bigger features and open a pull request to merge into `main`.
